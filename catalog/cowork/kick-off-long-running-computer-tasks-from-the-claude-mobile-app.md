# Kick off long-running computer tasks from the Claude mobile app

Check progress on a running task, give Claude Cowork the next instruction, and keep work moving — all from the Claude mobile app, without returning to your desk.

## Example prompt (verbatim, © Anthropic PBC)

```text
Go through every PDF in ~/Documents/Invoices/March-2026 and pull out the vendor name, invoice number, date, and total amount. Put all of it into a spreadsheet called march-invoices.csv in the same folder. Let me know when you're done.
```

## How it works (from source page)

1. Describe the task (specify files and desired output)
2. Give Claude context (grant folder access; no connectors required for basic file operations)
3. What Claude creates (processes files and delivers results)
4. Follow-up prompts (build on existing data, create summary files, schedule recurring tasks)

## Prerequisites (from source page)

- Computer must stay awake (enable keep-awake toggle in Dispatch settings)
- Folder access granted during Dispatch setup
- Optional: Gmail or Slack connectors for emailing/posting results
